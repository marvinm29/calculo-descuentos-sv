## Amenazas consideradas (threat model ligero)

| Amenaza | Vector | Control | Prueba |
| --- | --- | --- | --- |
| Datos corruptos/manipulados en localStorage | Usuario o extensión edita `localStorage` | Schemas Zod por clave + descarte + aviso (Regla 8) | fixtures corruptas por clave |
| XSS vía estado local | Valores no confiables renderizados | React escapa; no `dangerouslySetInnerHTML`; sin datos remotos | revisión `rg` (sin coincidencias) |
| Filtración de salarios | Logs/telemetría/UI de error | Sin telemetría; ErrorBoundary genérico + ID de soporte | `ErrorBoundary.test.tsx` |
| Dependencias vulnerables | `pnpm audit` | Gate `pnpm audit --prod --audit-level=low` | salida anotada en CHANGELOG |
| Abuso del API | Endpoint público | Rate limit por IP real (vigente, Regla 9) | tests API existentes |
| Fechas manipuladas por TZ | `toISOString()` UTC | Helper de fecha local (FR-FE-14) | `lib/fecha.test.ts` |
